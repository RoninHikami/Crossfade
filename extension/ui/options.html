Не подключено

Один раз нужно создать приложение Spotify — так Spotify разрешает доступ к вашей медиатеке. Это бесплатно и займёт пару минут.

Вам прислали Client ID чужого приложения? Пропустите шаги 1–3 и сразу вставьте его в шаг 4. Владелец приложения должен добавить вас в User Management.

  1. Откройте Spotify for Developers, войдите и нажмите Create app.
  2. Название и описание — любые. В поле Redirect URIs вставьте адрес и нажмите Add:
  3. В пункте Which API/SDKs are you planning to use? отметьте Web API, примите условия и сохраните.
  4. Скопируйте Client ID со страницы приложения и вставьте сюда:

Пока приложение в режиме разработки, Spotify пускает только тех, кто добавлен в его настройках (вкладка User Management). Если входите не тем аккаунтом, которым создали приложение, — добавьте его туда.

Автоматический перенос

Работает, пока открыт браузер. Направление — то же, что выбрано в окне расширения. О новых перенесённых треках придёт уведомление.

История

Не найдено

Этих треков нет в каталоге другого сервиса или они называются слишком по-другому. Можно найти их вручную по ссылке или поискать ещё раз позже — каталоги пополняются.

Недавно добавленные

    Сброс

    Расширение помнит, какие треки уже перенесло, чтобы не искать их повторно. Если сбросить историю, при следующем переносе все треки будут проверены заново. Лайки в сервисах при этом не меняются.
