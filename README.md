# Crossfade

Расширение для браузера, которое переносит лайкнутые треки между
**Яндекс Музыкой** и **Spotify** — в одну или в обе стороны, вручную по кнопке
или автоматически по расписанию.

- **Ничего не удаляет.** Расширение только добавляет лайки. Существующие лайки
  в обоих сервисах остаются как есть, а треки, уже лайкнутые в другом сервисе,
  повторно не трогаются.
- **Аккуратно сопоставляет треки:** по коду записи ISRC, если он есть, иначе по
  названию, исполнителям и длительности. Понимает транслит («Кино» = «Kino»),
  не путает студийную запись с концертной или ремиксом.
- **Помнит, что уже перенесено,** поэтому повторный перенос занимает секунды и
  берёт только новые лайки. Если остановить перенос или закрыть браузер,
  он продолжится с того же места.
- **Показывает, что не нашлось,** со ссылками на поиск в нужном сервисе.

Работает в Chrome и браузерах на его основе: Яндекс Браузер, Edge, Opera, Brave.

## Установка

1. Скачайте репозиторий: **Code → Download ZIP** на GitHub, и распакуйте архив.
2. Откройте страницу расширений: `chrome://extensions` (в Яндекс Браузере —
   `browser://extensions`).
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку `extension`.

После установки откроется страница настроек.

## Подключение сервисов

**Яндекс Музыка** — нажмите «Подключить» и войдите в свой аккаунт Яндекса на
открывшейся странице. Вкладка закроется сама.

**Spotify** — Spotify пускает к медиатеке только зарегистрированные приложения,
поэтому один раз нужно создать своё (бесплатно, пара минут). Пошаговая
инструкция с кнопкой «Копировать» есть прямо на странице настроек:

1. На [Spotify for Developers](https://developer.spotify.com/dashboard) нажмите **Create app**.
2. В **Redirect URIs** добавьте `https://lhphdnjhpigboedimofokakpbaaajobb.chromiumapp.org/`.
3. Отметьте **Web API** и сохраните.
4. Скопируйте **Client ID** в настройки расширения и нажмите «Подключить».

Пока приложение Spotify в режиме разработки, войти в него могут только
аккаунты, добавленные во вкладке **User Management**.

> Если вы раздаёте расширение другим людям, впишите свой Client ID в
> `extension/config.js`. Тогда им не придётся создавать приложение: шаги со Spotify
> for Developers пропадут, останется только кнопка «Подключить».

## Использование

Нажмите на значок расширения:

1. Выберите направление: **Яндекс → Spotify**, **Spotify → Яндекс** или **Обе стороны**.
2. Нажмите **Перенести лайки**. Прогресс виден в том же окне, его можно закрыть —
   перенос продолжится в фоне.
3. Включите **Автоперенос новых лайков**, чтобы новые лайки переносились сами
   (каждые 30 минут, час, 6 часов или раз в день, пока открыт браузер).
   О перенесённых треках придёт уведомление.

На странице настроек (значок шестерёнки) — история, список ненайденных треков
и кнопка «Поискать ещё раз».

## Как это устроено

```
extension/
  manifest.json          — описание расширения (Manifest V3)
  config.js              — Client ID Spotify (необязательно)
  background.js          — фоновая работа: вход, перенос, расписание
  lib/
    matching.js          — сравнение треков
    sync.js              — сам перенос и учёт уже перенесённого
    auth.js              — вход в Яндекс Музыку и Spotify
    http.js              — запросы с повтором при лимитах API
    services/yandex.js   — API Яндекс Музыки
    services/spotify.js  — Spotify Web API
  ui/                    — окно расширения и страница настроек
tests/                   — тесты (Node.js, без зависимостей)
```

Токены хранятся только в вашем браузере (`chrome.storage.local`) и никуда, кроме
самих сервисов, не отправляются.

Чтобы добавить ещё один сервис, нужен класс с методами `getLikedTracks`,
`search`, `searchUrl` и `like` — по образцу `lib/services/`.
